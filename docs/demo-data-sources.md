# Demo data sources (PRD §10)

All demo content in this repository is **synthetic**: it was written for KnowFlow and describes a fictional company,
"Northwind Labs". No real person, employer, customer, medical or financial data is included.

| Data | Location | Origin | Licence |
|---|---|---|---|
| Sample documents (5) | `samples/documents/` | Written for this project (2026-11-07). The vendor FAQ deliberately contains a prompt-injection paragraph for testing | Same as the repository |
| Evaluation gold set (50 cases) | `samples/evaluation/northwind-gold-v1.jsonl`, generated by `scripts/build_gold_set.py` | Questions and evidence quotes written against the sample documents; every quote is checked to exist verbatim | Same as the repository |
| SQL demo database | Generated by `apps/api/app/modules/sql_assistant/demo.py` (`./scripts/dev.ps1 seed-demo`) | Deterministic synthetic rows (fixed random seed 20261107): 120 customers (some share a name, some have NULL email/city), 16 products, 900 orders over the 12 months before seeding (paid / refunded / cancelled / pending), 2,168 order items, 864 payments including refunds | Same as the repository |
| Test fixtures | `apps/api/tests/files.py` | PDFs and DOCX built in code at test time; no binary files are committed | Same as the repository |

Email addresses use the reserved `example.test` domain.
